Hermes Personal プライバシーポリシー

最終更新日：2026年11月24日

1．このアプリについて

Hermes Personal は，開発者本人が自分の Google アカウントだけを操作するために使う個人用ツールです．一般には配布しておらず，開発者以外の利用は想定していません．

2．アクセスするデータ

本人が許可した範囲で，次の Google サービスのデータにアクセスします．

  • Gmail：メールの検索・閲覧，下書きや送信，ラベルの変更
  • Google カレンダー：予定の閲覧・作成・変更
  • Google ドライブ，ドキュメント，スプレッドシート：ファイルの閲覧・作成・編集
  • 連絡先：閲覧のみ

3．利用目的

本人の指示にもとづき，メールの確認，予定の登録，文書の作成など，本人の日常の作業を手伝うためだけに使います．広告，販売，ほかの人への提供には使いません．

4．データの扱い

  • データは開発者本人が管理するサーバーで処理します．
  • 認証トークンはそのサーバーに保存し，外部に公開しません．
  • 取得したデータを第三者に販売・共有しません．
  • Google API から得た情報の利用は，Google API Services User Data Policy（Limited Use の要件を含む）に従います．

5．アクセスの取り消し

アクセスはいつでも Google アカウントの「サードパーティ製のアプリとサービス」 から取り消せます．
